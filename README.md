# 5eTools_as_App
This repository includes the python 3.12.5 code and executable for the 5etools_App. This works be creating a self-hosted server and putting inside a specialized browser window. It also has the ability to download from Git the 5etools-src files and updates them on launch. This was coded  in Python 3.12.5 with assistance from Claude Sonnet 5.5
